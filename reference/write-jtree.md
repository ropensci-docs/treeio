# write.jtree

Export `treedata` object to json tree file

## Usage

``` r
write.jtree(treedata, file = "")
```

## Arguments

- treedata:

  `treedata` object

- file:

  output file. If file = "", print the output content on screen

## Value

output file or file content on screen
