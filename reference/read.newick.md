# read.newick

read newick tree

## Usage

``` r
read.newick(file, node.label = "label", ...)
```

## Arguments

- file:

  newick file

- node.label:

  parse node label as 'label' or 'support' value

- ...:

  additional parameter, passed to 'read.tree'

## Value

phylo or treedata object
