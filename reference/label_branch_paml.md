# label_branch_paml

label branch for PAML to infer selection pressure using branch model

## Usage

``` r
label_branch_paml(tree, node, label)
```

## Arguments

- tree:

  phylo object

- node:

  node number

- label:

  label of branch, e.g. \#1

## Value

updated phylo object
