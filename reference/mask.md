# mask

site mask

## Usage

``` r
mask(tree_object, field, site, mask_site = FALSE)
```

## Arguments

- tree_object:

  tree object

- field:

  selected field

- site:

  site

- mask_site:

  if TRUE, site will be masked. if FALSE, selected site will not be
  masked, while other sites will be masked.

## Value

updated tree object
